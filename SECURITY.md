# Security and support

Do not publish passwords, access tokens, secret payloads, private keys,
Terraform state, unredacted logs, or customer documents in this repository or
in a public GitHub issue.

For ASM+ deployment, configuration, security, or operational assistance, use
the [Auritas contact page](https://www.auritas.com/contact-us/) or email
`connect@auritas.com`. Include the Marketplace product and release, customer
project ID, Infrastructure Manager deployment ID, approximate failure time and
time zone, and sanitized error messages.

Access to Google Secret Manager, Infrastructure Manager state, database
backups, and support artifacts must follow the customer's approved privileged
access and data-handling processes.
