# Legacy Terraform Kubernetes package

This directory preserves the Terraform Kubernetes module and example inputs
that were prepared for the superseded ASM+ Marketplace product.

Auritas changed the intended Marketplace model to **Standard Kubernetes with
BYOL**. Google advised that the existing Terraform Kubernetes product cannot be
converted and that a new product must be created. Consequently, this module is
retained only for traceability and must not be presented as the deployment
package for the new Standard Kubernetes product.

Do not delete its remote Marketplace artifacts or the former Producer Portal
product until Google confirms the retirement procedure.
